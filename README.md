# 🌍 SillyTavern Card Forge · 酒馆卡锻造工坊

一个**纯本地**的 SillyTavern（酒馆）卡片制作工具：无需安装依赖、无需联网、数据不出本机。

既能做**世界观卡**（核心是世界而不是单个角色），也能做传统**角色卡**，并可独立编写**内嵌世界书**与**非内嵌世界书**。这是社区现成世界卡的普遍结构：
总纲说明「这个世界是什么、由谁讲述」，大量细节拆进内嵌世界书，开局提供多个故事入口，
输出由条例约束，界面由正则负责，再配一套统一的前端面板。

| 层 | 对应字段 | 作用 |
|---|---|---|
| ① 作品 | `name`、`creator`、`tags`、`creator_notes` | 作品信息与作者备注 |
| ② 世界观 | `description`、`scenario` | 世界总纲与世界当前情况 |
| ③ 叙事 | `personality`、`mes_example`、`system_prompt`、`post_history_instructions`、`extensions.depth_prompt` | 文风、示例、系统与深度提示 |
| ④ 条例 | `description` / `post_history_instructions` / `system_prompt` 尾部 | 行为规则：什么能写、什么不能写 |
| ⑤ 开局 | `first_mes`、`alternate_greetings`、`group_only_greetings` | 多个故事入口，酒馆里可左右切换 |
| ⑥ 世界书 | `character_book` | 碎片设定，按关键词或常驻注入 |
| ⑦ 界面 | `extensions.regex_scripts`、其他 `extensions` 键 | 状态栏、隐藏标签等显示层正则 |
| ⑧ 前端 | 占位符 + 渲染正则 + `extensions.wc_source.ui` | 统一的世界面板（HTML UI） |

## ✨ 功能

### 作品列表
- 本机保存多个作品（IndexedDB），可切换、复制（做变体）、删除
- 顶部实时显示每个作品的世界书条数与修改时间

### 内嵌世界书
- **分类**：条目标题用 `【分类】标题` 写法（地理 / 势力 / 历史 / 人物 / 物品 / 规则 / 事件 / 其他），可筛选、看统计
- **模板新建**：一键新建「世界规则（常驻）/ 地点 / 势力 / 人物 / 物品 / 历史 / 事件」骨架，关键词已预填
- **分页渲染**：几百上千条也流畅（每页 30 条，高级设置展开时才生成）
- **关键词触发测试**：粘贴一段剧情，立即看到哪些条目会被注入（支持次级关键词四种逻辑、全词匹配、正则关键词、常驻）
- **原生互转**：导入 / 导出 SillyTavern 原生世界书（`entries` 为 uid 对象或数组）
- **无损**：酒馆原生的未知字段（如 `uid`、`characterFilter`、`triggers`、`automationId`）原样保留并在导出时写回

### 条例（可自定义、可删除）
- **内置条例库**：12 条常用规则（不替玩家行动、设定一致、小步推进、后果有因果、NPC 有独立意志、感官细节、篇幅节奏、状态栏更新、不擅自跳时间、称呼统一、不打破第四面墙、保留选择权）
- 每条可选写入字段：世界总纲 / 历史后指令（权重最高）/ 系统提示
- 支持**停用、编辑、删除、自行新建**；已添加的库条例会标记，不会重复添加
- 导出时把启用的条例追加到对应字段末尾；导入时从 `extensions.wc_source` 还原原文，**二次导出不会叠加**

### 文风基调
- 8 种基调可多选（冷峻写实 / 史诗宏大 / 温情细腻 / 悬疑诡异 / 轻松幽默 / 古典雅致 / 黑暗压抑 / 日常生活）
- 可设叙述视角、时态、篇幅、对白占比、节奏与补充要求，一键生成到「叙事基调」字段，之后仍可手改

### 开局
- 主开局 + 任意多个备用开局（可排序）+ 群聊开局（V3）
- 状态栏模板（HTML / 文字）、开局选项菜单模板

### 粘贴智能解析
把自己写好的世界观整段粘进来，工具会自动分块并归位：

- **角色卡字段**：识别「角色名 / 核心设定 / 性格 / 场景 / 开场白 / 对话示例 / 作者备注 / 系统提示 / 历史后指令 / 作者 / 版本 / 标签」等标签，写入对应字段
- **世界书条目（可选）**：识别「地点 / 势力 / 人物 / 物品 / 规则 / 历史 / 事件 / 世界观」等标签，分割为带分类、关键词的条目
- **多开局**：「开场白」作主开局，「备用开局 / 开场白二」等自动归入备用开局，按序号或出现顺序排列
- **显式关键词**：条目内容里写「关键词：A, B」优先使用，否则取标题
- **长内容拆分**：可选把超长设定按空段拆成多个条目
- **JSON 直通**：粘 JSON 角色卡 / 世界书直接走既有导入逻辑
- **只补空缺**：已有内容的字段不会被覆盖，可切到「写入新作品」

支持 `【标签】内容`、`标签：内容`、`# 标题`、`<tag>`、空行分段等写法；「标签：内容」这种宽松写法只用于卡片字段，条目内的「位置：」「氛围：」等子标题会保留在内容里。
### 界面与扩展
- 正则脚本编辑器（placement、仅显示 / 仅提示词、深度范围），保留酒馆内部的其他 placement 值
- 一键模板：隐藏思维链与内部标签、状态栏标签渲染
- **统一前端（世界面板）**：4 套内置模板（状态栏 / 开局面板 / 世界信息面板 / 简约条）+ 6 套配色，可改标题、增删字段、自定义颜色；一键「应用」即自动把占位符 `<WorldPanel/>` 插入开局并生成渲染正则，玩家在酒馆里看到的就是这个面板。面板采用「渐变外框 + 内容面板」结构，标签与数值分层、固定标签列宽，保证在渐变背景上依然清晰易读
- **酒馆助手脚本**（`tavern_helper`）：结构化编辑，含 MVU 变量表 / 开局面板 / EJS 模板骨架
- **原生扩展**：直接编辑 `extensions` 里的其他键（如 QuickReply 配置），导入的键原样写回

### 预览与体检
- **开局预览**：消息在隔离 iframe 中渲染，卡内 `<style>` 与 HTML 状态栏照实显示；`{{char}}` / `{{user}}` / `{{time}}` / `{{date}}` 宏替换；可勾选「应用正则显示效果」；脚本与外部资源不加载，并给出说明
- **体检条**：作品名、主开局、备用开局、条例数、世界书条目数（常驻数）、正则数、体积，以及缺失项提示

### 编辑现成角色卡
把别人的卡（PNG / JSON）导入后可直接改：

- **不污染原文**：导入外部卡时不会注入本工具的默认条例，`description` / `post_history_instructions` 等字段保持原样
- **字段全量回填**：name / description / personality / scenario / first_mes / mes_example / creator_notes / system_prompt / post_history_instructions / tags / creator / character_version 及备用开局、群聊开局、内嵌世界书、正则、助手脚本全部还原
- **大卡可编辑**：世界书条目分页渲染（每页 30 条），700+ 条的卡也能流畅操作；所有文本框自动增高（上限 600px），上万字的开场白和条目内容不会被压在几行高的小框里
- **无损再导出**：酒馆原生未知字段（`uid`、`characterFilter`、`triggers`、`automationId` 等）原样写回；`null` 继承语义、`role` 数字写法、uid 为 0 的条目都不会被改写
- **重新导入自旋一致**：导入 → 导出 → 再导入，内容完全一致
### 导入 / 导出 / 存档
- 导入：V1 / V2 / V3 卡（PNG 或 JSON）、原生世界书 JSON、正则 JSON、MD 存档、图片封面（拖入即可）
- 导出：PNG 世界卡（V3 同时写 `ccv3` + `chara`，写入后立即读回校验）、JSON、原生世界书
- `extensions.world` 自动与世界书名同步，导入酒馆时可关联内嵌世界书
- 设置保存目录（Chrome / Edge）后 PNG / JSON / MD 直接写入该目录；MD 存档可反向恢复
- 作品库与封面自动保存在浏览器 IndexedDB，误关页面可恢复

### AI 扩写世界（可选）
填入 OpenAI 兼容接口、密钥与模型，输入一两句世界构想，即可生成总纲、场景、开局、备用开局与 6–12 条分类世界书条目。

### 快捷键
`Ctrl+1`~`Ctrl+7` 切换左侧页签 · `Ctrl+S` 导出 JSON · `Ctrl+Enter` 生成 PNG · `Ctrl+Shift+V` 粘贴解析

## 🔍 逆向推导：本工具能写出什么样的卡

以社区现成世界卡为样本反推，结论如下。

**可以完整写出**
- 世界总纲 / 讲述者设定 / 当前处境（`description`、`scenario`）
- 多个开局入口，包括用「占位符 + 正则替换」实现的开局面板（`first_mes` + `alternate_greetings` + `regex_scripts`）
- HTML / 文字状态栏及其显示正则
- **统一前端**：内置模板生成自包含 HTML 面板，占位符插入开局、渲染正则自动同步，配置存于 `extensions.wc_source.ui` 无损往返
- 数百条规模的内嵌世界书，含分类、常驻、次级关键词、位置 / 深度 / 概率 / 递归 / 冷却 / 分组等全部常用参数（含 `uid` 为 0 的条目、`null` 继承语义、`role` 数字写法）
- 独立世界书（非内嵌）：世界书库可建多本，导出酒馆原生格式，含全部 41 个原生字段，与卡内世界书互转
- **酒馆助手脚本**（`tavern_helper`）：结构化编辑器（名称 / 类型 / 启用 / 内容 / 排序 / 复制），提供 MVU 变量表、开局面板、EJS 模板骨架；对象与数组两种形态、`variables` 等附加键、脚本的 `info`/`button`/`data`/`export_with` 均原样保留
- 深度提示、群聊开场、作者备注、`extensions.world` 关联、V3 顶层元信息（`creator` / `character_version` / `creator_notes`）
- 导入→导出无损（未知字段与扩展键原样写回）；内部作品（草稿 / 作品库 / MD 存档）保留条例与文风

**只能保留、不能在本工具内编写**
- 第三方插件配置（`QuickReply_Profile_V54`、`TavernHelper_scripts`、`odysseia_trace` 等）：可在「原生扩展」里整体编辑 JSON，没有专用编辑器
- 依赖外部 CDN 的 HTML 面板：预览不加载外部资源与脚本（酒馆中可正常显示）

## 🗂 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` / `style.css` | 界面与样式 |
| `app.js` | 界面逻辑（作品库、世界书库、表单、条例、文风、预览、导入导出、粘贴解析、AI） |
| `card-model.js` | 数据模型（纯函数）：归一化、无损往返、原生世界书互转、关键词触发模拟、条例拼接、助手脚本、导出包 |
| `png-card.js` | PNG 角色卡元数据读写（tEXt + base64） |
| `test_model.js` | 数据模型测试（`node test_model.js`，含粘贴解析；135 + 164 项断言） |
| `test_card.js` | PNG 读写回环测试（`node test_card.js`，21 项） |
| `启动制卡工具*.bat` | 启动脚本 |

### 技术原理
PNG 世界卡 = 普通图片 + 内嵌元数据：卡 JSON 转 UTF-8 再 base64，写入 PNG 的 `tEXt` 块，关键字 `chara`（V2）与 `ccv3`（V3）。
条例在导出时拼接进目标字段，未拼接的原文与条例列表记录在 `extensions.wc_source`，用于重新导入时还原。
